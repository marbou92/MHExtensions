Extensions

Browse and download manga sources for Mihon and variants. Install the APK directly, or add the repo once and let the app manage updates.

Add the repo to your app

Mihon → More → Settings → Browse → Extension repositories → Add repository → paste this URL:

https://raw.githubusercontent.com/marbou92/MHRepo/main/repo.json Open in app

⚠️ Couldn't load the extension list

index.json could not be fetched. When browsing locally, serve this folder over HTTP (e.g. python3 -m http.server -d docs). On GitHub Pages it loads automatically — regenerate it with python3 .github/scripts/generate-site-index.py or the Update website index workflow.
