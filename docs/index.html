⚠️ Extension list says my app is outdated

If you are seeing an empty extension list with the message "Outdated app", or all extensions showing as obsolete, it means your app is no longer compatible with these extensions. MHExtensions only supports Mihon, TachiyomiSY and Komikku — make sure your app is updated to the latest version!

This is a personal extension repository: extensions are built from marbou92/MHExtensions and published to marbou92/MHRepo with their own signing key.
