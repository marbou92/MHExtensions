Guide

How to add the repo, install extensions and fix common issues.

Adding the repository

Visit the Add store page and either use the deep link or copy the repository URL: 

https://raw.githubusercontent.com/marbou92/MHRepo/main/repo.json

In Mihon: More → Settings → Browse → Extension repositories → Add repository, paste the URL and confirm. Then open Browse → Extensions and refresh.

Installing extensions

  1. Open Browse → Extensions. Sources are grouped by language (use the Languages filter to pick what you read).
  2. Tap Install next to an extension. On the first install the app asks you to trust the repo's signing key — accept it once.
  3. Enable the individual sources under Browse → Sources (multi-language extensions publish one source per language).

Updating extensions

The app checks the repo index automatically — when an extension is bumped and republished to MHRepo, the update shows up like a normal app update. Nothing to do by hand.

Troubleshooting

  • Empty extension list / "Outdated app" — your app is no longer compatible. MHExtensions only supports Mihon, TachiyomiSY and Komikku; update your app.
  • Cloudflare check inside the app — some sources (Comix, Kagane, MangaGo, MangaDot, ManhuaRMTL…) ride a WebView-based Cloudflare solver. If a challenge appears, complete it once in the WebView window; the clearance is reused afterwards.
  • MKissa shows no chapter images — that's intentional: the site's anti-bot token explicitly blocks scraping. Browse, search, details and the chapter list work; open the chapter on the site for now.
  • 403 / invalid token errors — the source site changed its protection layer. File an issue.
