Add store

Add the MHExtensions store to the app, then install extensions straight from Browse → Extensions.

Repository URL

Copy and paste this into the app's extension repository settings:

https://raw.githubusercontent.com/marbou92/MHRepo/main/repo.json
Open in app (deep link)

The deep link only works on a device that has Mihon, TachiyomiSY or Komikku installed. If nothing happens, use the copy button and the manual steps below.

Manual steps (Mihon)

  1. Open More → Settings → Browse.
  2. Scroll to Extension repositories and tap Add repository.
  3. Paste the URL above and confirm.
  4. Go to Browse → Extensions, pull down to refresh — the MHExtensions catalog appears.
  5. Tap Install on an extension, then enable its sources under Browse → Sources.

What the app downloads

repo.json points the app at the protobuf index (index.pb) on marbou92/MHRepo, which lists every extension with its version and signing-key fingerprint. APKs are signed — the app verifies them against the fingerprint before installing.

⚠️ First install warning

On the first install from a new repo, the app asks you to trust its signing key once. Accept it — the fingerprint is published in the repo index.
