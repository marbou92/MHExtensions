## Usage

**If you are new to repositories/extensions, please read the [Getting Started guide](https://marbou92.github.io/MHExtensions/guide/#adding-the-repository) first.**

* You can add our repo by visiting the [MHExtensions Website](https://marbou92.github.io/MHExtensions/add-repo/)
* Otherwise, copy & paste the following URL: https://raw.githubusercontent.com/marbou92/MHRepo/main/repo.json

## Requests

To request a new source or bug fix, [create an issue](https://github.com/marbou92/MHExtensions/issues/new/choose).

Please note that this is a personal, spare-time project — creating an issue does not guarantee that
the source will be added or fixed in a timely fashion. Some sources may also be impossible to do or
prohibitively difficult to maintain.

If you would like to see a request fulfilled and have the necessary skills to do so, consider
contributing! Issues are up-for-grabs for any developer if there is no assigned user already.

## Website

This repo ships a keiyoushi-style website in [`docs/`](docs/) — an extension browser, an add-repo
page and the guides, on clean directory URLs (`/extensions/`, `/add-repo/`, `/guide/`). Plain
HTML/CSS/JS, zero build step.

**https://marbou92.github.io/MHExtensions/**

To publish it: push this repo, then enable **Settings → Pages → Deploy from a branch → `main` → `/docs`**.
The extension catalog (`docs/index.json`) regenerates automatically via the *Update website index* workflow.

## Publishing extensions

1. Bump `versionCode` in the extension's `build.gradle.kts`
2. Commit and push to `main`
3. **Actions → Release & Publish → Run workflow** → `publish`

The workflow builds signed release APKs for all extensions in `settings.gradle.kts` and publishes
APKs, icons and the protobuf index (`index.pb`) to [MHRepo](https://github.com/marbou92/MHRepo) —
the repository URL Mihon consumes — then purges the jsDelivr CDN cache. Full details (signing
secrets, cleanup mode) live in [MAINTAINING.md](MAINTAINING.md).
